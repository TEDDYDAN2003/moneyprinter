# Offline M15 gold research

Research only: no orders, no calibrated forecast, and no trading recommendation. See `reports/ml-2024-2026-report.md` for exact definitions, chronology, candidate-label limitations, cost assumptions, missing-data exclusions, model results, No-Wick exclusion and important caveats. The previously checked Jan–June 2026 period has now been consumed and cannot be called an unseen final test after retuning.

Use a dedicated Python environment with `pip install -r research/ml/requirements.txt`. Set `OANDA_API_TOKEN` privately in the terminal (never source control or chat), then run `python research/ml/fetch_oanda.py` and `python research/ml/pipeline.py` from repository root. The latter fits only on 2024, validates on 2025 and evaluates frozen settings on January–June 2026. Data, raw results and trade records remain in ignored `research/data/`. No runtime model is deployed. Verify OANDA dates, credentials and account eligibility; API tokens grant account access.

Run deterministic tests with `PYTHONPATH=research/ml python -m unittest discover -s research/ml -p 'test*.py'`. This first implementation uses EMA and tick-VWMA proxies, not the chart's smoothed proxy indicator, and does not implement the full Moneyprinter Pullback, Volume Profile or all strategy checklists. CPI/PPI news is not identifiable without a calendar. Missing bars are excluded rather than silently fabricated, and P&L for such trades remains unknown.

For the chart comparison, see `reports/chart-vwma-oanda-comparison.md`. After fetching data, run `node research/ml/extract_chart_proxy.cjs`, `node research/ml/extract_tick_proxy.cjs` and `python research/ml/chart_crossover_study.py`. The first executes the existing chart calculation directly; the second creates a research-only same-code variant with just the range/body proxy swapped for OANDA tick volume. Neither changes the chart. The chart viewport's 300-bar warmup can change EMA grades versus continuous-history research; the report includes a limited parity diagnostic.

For the subsequent exact-chart 2024–2025 supervised/confluence study, see `reports/vwma-confluence-2024-2025.md`. From the repository root, run `node research/ml/extract_chart_2024_2025.cjs` and `python research/ml/vwma_confluence_research.py`. Only 2024–25 are evaluated; the code filters all other dates before indicator and feature calculation. The study did not qualify a model for promotion. Candidate scores are uncalibrated, gap outcomes are unknown, and the 2025 comparison has already been observed, not an unseen final test.

For the separate 2023–2025 exact-chart structure/entry/exit comparison, see `reports/vwma-structure-2023-2025.md`. With a private environment-only `OANDA_API_TOKEN`, run `python research/ml/fetch_2023_2025.py` (or `--reuse-2024-2025` to retrieve only 2023 and reuse the local earlier snapshot), then `node research/ml/extract_chart_2023_2025.cjs` and `python research/ml/structure_2023_2025.py`. The reused file is filtered before calculations; no 2026 candles enter this study. Raw files and results are ignored, and access tokens must never be committed. The study excludes unresolved gap trades and uses hindsight year-boundary purging; results are not live-executable, and no tested variant qualified.

For the follow-up execution replay, see `reports/vwma-execution-improvements-2023-2025.md`. Run `PYTHONPATH=research/ml python research/ml/execution_research_2023_2025.py` after preparing the same private snapshots. This carries positions through observed missing intervals using an explicit non-tradable-gap assumption, applies illustrative commissions and cost-aware planned-risk sizing, estimates intrabar floating drawdown, compares exits, and outputs trade and near-miss CSVs. The missing interval's actual prices and executions remain unknowable; the floating drawdown is only an OHLC proxy. This script imports the preceding research module with `runpy`, so it regenerates that module's ignored intermediate results. The results are research, not live-trading rules.

For the no-overnight follow-up and 2023–2024 loss analysis, see `reports/vwma-intraday-loss-analysis-2023-2025.md`. Run `PYTHONPATH=research/ml python research/ml/intraday_vwma_2023_2025.py` with the same private 2023–25 snapshots. The conservative 12:45 New York cutoff was chosen after inspecting historical gaps, is not a verified future holiday schedule, and can cause substantially earlier exits than ordinary close. Unexpected gaps are labeled unknown; no inspected year is an unseen validation set. The run rewrites ignored intermediate structure-study data.

For the liquidity-sweep and consolidation-box study, see `reports/vwma-liquidity-consolidation-2023-2025.md`; run `PYTHONPATH=research/ml python research/ml/liquidity_consolidation_2023_2025.py` with the prepared private 2023–25 snapshots. The descriptive sweep and consolidation proxies use only completed current/prior candles and contiguous history. The retrospective breakout candidate has very small samples and did not satisfy the study's frequency/sample screen; none of the years is an unseen holdout. No live indicator or execution strategy is changed.

For the four complementary intraday setup tests, see `reports/vwma-complementary-setups-2023-2025.md`. Run `PYTHONPATH=research/ml python research/ml/complementary_vwma_2023_2025.py` with the same private 2023–25 snapshots. It tests breakout retests, H4-aligned VWMA pullbacks, post-breakout consolidation continuation, and confirmed-swing sweep/reclaim entries separately and in sequential one-position portfolios. All-five combined results lost in all three inspected years; these are research proxies, not live execution rules. The script uses the same early New York cutoff and regenerates ignored intermediate structure-study data.

For the supervised confluence CSV and chronological model comparison, see `reports/vwma-ml-confluences-2023-2025.md`. With the private 2023–25 snapshots prepared, run `PYTHONPATH=research/ml python research/ml/confluence_ml_2023_2025.py`. The CSV separates close-time `feat_` fields from subsequent `outcome_` labels and flags in-sample training scores. The 2024 H2 validation and 2025 check have both been examined in earlier research; neither is an untouched final strategy holdout. The candidate labels assume fixed $1,000 and do not form a sequential account. Neither model met its validation screen and no model is deployed.

For the online-informed deterministic entry/checklist hypothesis study, see `reports/vwma-online-entry-research-2023-2025.md`. Run `PYTHONPATH=research/ml python research/ml/entry_hypotheses_2023_2025.py` with the same private 2023–25 snapshots. It tests a fixed 15-configuration list including ADX/DI, candle confirmation, ATR, optional FVG and retest timing, with base and cost stress. No new pullback or retest variant produced positive net in all three inspected years. The research checklist is not a live rule. Candidate-generator metadata for breakout/retest identity is additive and prior comparison CSVs remain byte-identical.

For the bounded systematic search, see `reports/vwma-systematic-search-2023-2025.md`; run `PYTHONPATH=research/ml python research/ml/systematic_vwma_search_2023_2025.py` with the prepared private 2023–25 snapshots. It replays 81 fixed configurations across three years at base and stressed costs, using 2023–24 for a retrospective screen and showing 2025 only as an already-inspected comparison. None passed both development years; the best higher-sample diagnostic also lost in 2025 and is not deployed. This is not an exhaustive search of all possible strategies.
