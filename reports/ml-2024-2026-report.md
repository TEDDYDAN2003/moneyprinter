# XAU/USD 15-minute machine-learning research — first offline run

## Decision

**No model is approved for live use.** This is an offline research foundation and a first comparison, not proof of a profitable strategy. The probability scores were less accurate than a simple constant-rate reference by Brier score on both later periods, and no validation candidate met the selection criteria. The diagnostic model made only one trade in the 2026 comparison. The resulting out-of-sample period has now been inspected and must not be reused as an untouched final test after further changes.

No No-Wick indicator or No-Wick structure engine was used. The baseline in this report is a simple EMA-aligned candidate strategy, **not** the existing No-Wick-based Institutional Triad; comparing directly to that Triad would conflict with the request to omit No-Wick and remains unfinished.

## Data and chronological controls

- Source: OANDA practice, completed XAU_USD M15 midpoint, bid and ask OHLC plus tick volume. API access was read-only; no orders were sent. 60,865 candles from December 2023 to June 2026; December is warmup. Local snapshot SHA-256 `ccd16272077e0065f766354a0573f0bcde78f8afdb8479842800e2083e5add66`. The full private snapshot and credentials are not committed.
- Fit: 2024. Model/threshold development and ablation: 2025. Later check: January 1 through June 30, 2026 **UTC**, a period not previously inspected in the documented October study. This check is now consumed. Models are fitted on 2024 only; 2025 is not added to training after selection.
- Any candidate whose outcome is not known before its split ends is purged from that split. 4-hour features use only complete, UTC-aligned 16-candle groups whose close time has passed, with an eight-hour staleness limit. Other features and 3-left/3-right confirmed pivots use completed candles only. The next-candle entry follows the signal close. Synthetic fixtures were used only in unit tests, never for the historical results.
- Candidates can overlap in the supervised dataset; observations and error estimates are therefore correlated. Candidate eligibility also depends on whether the next open yields a valid stop and risk geometry; scores and calibration are therefore conditional on executable candidates, not all signal candles. The replay permits only one active position and at most two entries per UTC day. Candidate availability, risk rejection and trade path differ between strategies.

## Rules and engineered features

The candidate generator uses a simple 14-bar **OANDA tick-volume-weighted moving average versus EMA20** cross or same-candle VWMA reaction. Each candidate may be long or short. This is **not identical** to the Moneyprinter custom chart “VWMA” indicator, which uses a smoothed price-range-based volume proxy; it is a transparent alternative. The underlying tick volume is a count of OANDA price updates, not total market trading volume.

Features include 4h EMA50/EMA200 trend alignment, 15m EMA50/EMA200 internal-direction proxy and slope, distance to EMA200/VWMA in ATRs, prior-20-bar sweep and reclaim, first FVG touch, FVG invalidation/flip proxy, prior confirmed-pivot close-break (BOS proxy), an opposite-EMA-direction close-break (MSS proxy), simple engulfing/rejection-wick descriptions, candle body and close position, relative tick volume, current range / prior ATR and prior ATR versus its 96-bar median. These are transparent computational **proxies**, not equivalent to full discretionary structure, certified IFVG retests or the user's No-Wick method. FVG is never mandatory. Current-bar features are available only at that candle's close.

London 07:00–10:00 UTC, overlap 12:00–15:00 UTC and NY 15:00–17:00 UTC are fixed UTC windows from the app; they do not automatically track daylight-saving changes. The model can use session identity but is not proof of session-specific edge. It is not the full Pullback Strategy, Volume Profile, order-block, lower-timeframe MSS or candle-pattern library; those strategies require additional causal definitions and validation.

## Trade and cost model

- Signal candle close → next candle open. Buy uses OANDA ask open, exits use bid; sell uses bid open, exits use ask. SL uses the most recent confirmed opposing swing with max($0.20, 0.15× previous 20-bar ATR) buffer. Stop distance must be 0.2–25 ATR/dollar conditions as implemented (≥0.2×ATR and ≤$25/oz).
- Target uses the last confirmed opposing swing only if 1–3R away; otherwise a fixed 1.5R fallback, clearly identified in the trade CSV. This is a simple structural target, not a complete liquidity map. Maximum holding window is 48 M15 candles; timeout exits at bid/ask close.
- Base case adds **$0.10/oz per side** slippage; stress adds $0.30/oz per side. Actual OANDA historical bid/ask OHLC provides spread, but not intrabar order, execution depth or broker-specific Exness costs. Commission, financing, margin/closeout and market impact are not modeled. $1,000 balance, 100 oz/lot, 0.05 maximum, 0.01 lot increments and 2% planned risk; slippage/gaps can exceed planned risk.
- If both exits are touched on one bar, the simulator uses a stop loss and labels it ambiguous. Such bars are **excluded from model training labels**, but conservatively included as losses in replay. If history has a gap before resolution, the event is excluded and account balance is left unchanged, not treated as a real flat fill. This is a substantial limitation: 525/2,140 training candidates, 463/2,205 validation candidates and 57/635 test candidates were gap-excluded, and 29 validation/3 test baseline replay entries were affected. Results may be biased by these exclusions.
- Profit factor is based on simulated net dollars, and max drawdown is **closed-balance**, not mark-to-market equity. Open-position margin risk and the actual intrabar sequence are unknown.

## Model setup and validation

Label: whether resolved net dollars per unit are positive, including timeout exits; ambiguous and gap labels are excluded. Logistic regression with standardized features and a shallow depth-3 decision tree were trained on 2024. Six fixed thresholds (0.50, 0.55, 0.60 per model) were evaluated on 2025. A model would have needed at least 30 validation trades, positive net P&L and profit factor >1 to be a candidate; none qualified. A logistic 0.55 diagnostic was fixed before evaluating 2026, but it failed the selection threshold and is **not an approved model**.

| 2025 validation | Trades | Win rate | Net $ | Profit factor | Max closed DD |
|---|---:|---:|---:|---:|---:|
| EMA-aligned baseline | 207 | 38.65% | −167.59 | 0.900 | 37.06% |
| Logistic, 0.50 threshold | 76 | 34.21% | −201.64 | 0.721 | 26.00% |
| Logistic, 0.55 threshold | 16 | 50.00% | +83.49 | 1.675 | 9.86% |
| Decision tree, 0.50 threshold | 110 | 31.82% | −359.70 | 0.604 | 37.64% |

The positive 0.55 validation result has only 16 closed trades and did not satisfy the predeclared 30-trade minimum. The higher thresholds and additional exploratory ablations increase selection risk. Do not interpret the best-looking row as a verified edge.

## January–June 2026 later check

| Method | Trades | Win rate | Net $ | Profit factor | Avg net R | Max closed DD |
|---|---:|---:|---:|---:|---:|---:|
| EMA-aligned baseline | 68 | 35.29% | −122.90 | 0.813 | −0.1414 | 22.67% |
| Diagnostic logistic ≥0.55 | 1 | 0.00% | −13.50 | 0.000 | −1.0075 | 1.35% |

Both exclude gaps as described above. Over the roughly 25.9-week test period, the baseline averaged approximately 2.6 closed trades per calendar week and the diagnostic about 0.04 per week; neither met a dependable one- or two-trade-per-day goal. One diagnostic trade cannot establish model performance. Increasing assumed slippage to $0.30/oz **per side** gave baseline 62 trades, −$251.36, PF 0.608, max closed DD 28.83%; the diagnostic still had one loss of −$13.90. This stress replays the original model and feature definitions, not a retuned model. Different fills/sizing and account path explain changes in trade count.

For context only, the 2026 baseline's closed trades in the existing sequential run were London: 33 trades, 8 positive, −$180.27; overlap: 33 trades, 15 positive, +$52.92; NY: 2 trades, 1 positive, +$4.45. These are small, conditional, dependent samples; do not infer a reliable session rule from them.

## Calibration and feature research

Brier score is lower-is-better for predicting a positive net result among labelable candidate events, **not only executed trades**:

| Comparison | 2025 | 2026 |
|---|---:|---:|
| Logistic | 0.2404 | 0.2417 |
| Decision tree | 0.2448 | 0.2564 |
| Constant rate from 2024 training (37.48%) | 0.2322 | 0.2325 |

The constant reference scored better than both models. For example, 98 validation candidates with logistic scores from 0.50 to 0.60 averaged 0.526, but only 35.7% had positive net results. This is evidence against treating those scores as calibrated probabilities, not a reliable estimate of future win rate.

The largest standardized 2024 logistic coefficients included 4h EMA alignment (+0.233), relative tick volume (+0.157), crossover (−0.133) and trade direction (+0.107). Coefficients are conditional and affected by correlations; they do not establish cause or a safe rule. In **2025 exploratory** feature-group ablations, removing 4h alignment improved candidate Brier from 0.2404 to 0.2372, and removing tick-volume ratio produced a 50-trade replay of +$52.09 versus the full model's 76-trade −$201.64 at threshold 0.50. Different filters create different trade paths. These are multiple exploratory comparisons, not proof that either feature should be removed or that the ablated rule works in 2026; no ablated model was promoted.

For small versus large movement, we grouped 2025 baseline candidates by prior ATR relative to its 96-bar median: below 0.8 (47 closed, −$169.97), 0.8–1.2 (154, −$278.70), and above 1.2 (55, +$100.00). Each bucket was independently replayed, so those counts and P&Ls cannot be summed or compared as matched trades. This was exploratory and can include CPI, PPI, other announcements or ordinary moves. **No calendar was supplied, so the pipeline cannot identify or exclude CPI/PPI and cannot claim to isolate non-news swings.** The ATR features can describe past volatility, not predict a release.

## What to do next

1. Do not use this model for live trades. Resolve missing history and compare gap handling, mark-to-market equity drawdown, broker contract/margin, bid/ask ordering, commissions and slippage.
2. Specify and independently implement actual Moneyprinter chart VWMA crossover parity, the full anchor/grab/close-break Pullback sequence, and other strategies as separate causal setups; do not pretend the proxies validate them. Test those changes on a new untouched period because January–June 2026 has now been inspected.
3. Use a trustworthy historical and forward CPI/PPI calendar if the requirement is to exclude news moves. A candle-outlier feature is not a news identifier.
4. With sufficient samples, run expanding walk-forward splits, realistic trading and confidence intervals, feature ablations on development only, and then a frozen final holdout. Compare against an explicit **No-Wick-free** rule baseline and paper trade before considering deployment.

## Reproduce locally

From the repository root: install dependencies in a dedicated environment using `research/ml/requirements.txt`; set `OANDA_API_TOKEN` privately in the terminal; run `python research/ml/fetch_oanda.py` to obtain the snapshot, then `python research/ml/pipeline.py`. Use `PYTHONPATH=research/ml python -m unittest discover -s research/ml -p 'test*.py'` for deterministic gap, collision and prefix/H4 timing checks. The snapshot and raw model/trade artifacts are under ignored `research/data/`; the companion `ml-2026-trade-log.csv` contains the audit trade outcomes, not credentials. This run used NumPy 2.3.5, pandas 2.2.3 and scikit-learn 1.6.1; results may differ with other versions or provider history. Never deploy API secrets.
